# Medical Tort Mobile Form

This is a [Next.js](https://nextjs.org/) app. To run it locally:

```bash
npm run dev
# or
yarn dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

## What is this?

This project is a snippet of a website built for a client to accept medical tort leads. It has two pages:
/herniamesh1 (single step form)
/herniamesh2 (multi-step form)

With these pages I built a fun mobile animation that makes the first unanswered question of the form appear as a top bar when the user scrolls pass the form:
